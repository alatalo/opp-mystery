#  PERUSSÄÄNNÖT
#   - Rivi, joka alkaa risuaidalla (#), on kommentti. Se ei näy sivulla.
#   - Tyhjä rivi erottaa kappaleet.
#   - Avainsanat kirjoitetaan ISOILLA KIRJAIMILLA rivin alkuun (KUN, JOS, OTSIKKO ...).
#   - Kaikki teksti näkyy sivulla isoilla kirjaimilla, joten isoilla ja pienillä ei ole väliä.
#   - Puhelinnumeroa, sähköpostia tai osoitetta EI kirjoiteta tähän käsin. Käytä {puhelin},
#     {sähköposti}, {katu}, {postinumero}. Ne haetaan tiedostosta js/config.js.
#
#  KOHTAUS
#   == nimi                 uusi kohtaus alkaa. Nimi on pieniä kirjaimia ilman välilyöntejä (alku, ikkuna ...)
#   OTSIKKO: Teksti        kohtauksen otsikko (alaviiva tulee perään itsestään)
#   SÄÄ: päällä            sade, lumi ja salamat taustalle (vain alkukohtaukseen)
#
#  RUUDUT (jatka-napautukset)
#   ---                    uusi ruutu alkaa. Yksi ruutu = yksi tai kaksi kappaletta.
#                          Jos ruutuun ei mahdu kaikki, sivu jakaa sen itse.
#   Kohtauksen viimeinen ruutu on valinnat (rivit, jotka alkavat merkillä >).
#
#  VALINNAT JA LINKIT
#   > Teksti -> kohde      valinta. Kohde on kohtauksen nimi, www-osoite (https://...) tai
#                          puhelin, sähkö tai reitti (arvot haetaan config.js:stä)
#   [sana -> kohde]        linkki kesken kappaleen, samat kohteet
#   ? Teksti               "kysymysmerkkinappi": vitsi, joka aukeaa napautuksesta.
#                          Kuuluu rivin heti edellä olevalle kappaleelle tai valinnalle.
#
#  ERIKOISRUUDUT (omalle rivilleen)
#   NÄYTÄ hahmo            ASCII-hahmo kuvana
#   NÄYTÄ kortti           punainen aukioloilmoitus. Seuraavat rivit tyhjään riviin asti ovat kortin tekstiä.
#   NÄYTÄ kyltti           osoitekyltti. Seuraavat rivit ovat kyltin tekstiä.
#   NÄYTÄ kartta           osoite, reittilinkki ja kartta
#   NÄYTÄ kissa            pieni yllätys
#   KYSY nimi              lomakkeen kysymys (nimi, klaani, yhteys, viesti, vahvista), kysymysteksti on sen yllä
#
#  VAIHTOEHDOT ("galaksin asennot")
#   Kappaleen, valinnan, ruudun tai otsikon voi vaihtaa toiseen tietyllä ehdolla.
#
#     Tämä on tavallinen kappale (oletus).
#
#     KUN täysikuu JA yö
#     Tämä näytetään oletuksen tilalla, kun ehto pitää.
#
#     JOS auki
#     Tämä kappale näytetään VAIN jos ehto pitää, muuten ei mitään.
#
#     MUUTEN
#     Tämä näytetään JOS-kappaleen jälkeen, kun JOS-ehto ei pitänyt.
#
#   Ehdot (yhdistä JA:lla tai TAI:lla, EI kieltää):
#     kuu:       uusikuu, kasvava kuu, täysikuu, vähenevä kuu
#     kellonaika: aamu, päivä, ilta, yö
#     valo:      pimeää, valoisaa, hämärä, aurinko ylhäällä, yötön yö, kaamos
#     viikko:    maanantai ... sunnuntai, arki, viikonloppu
#     vuosi:     kevät, kesä, syksy, talvi, tammikuu ... joulukuu, juhannus, joulu, vappu
#     kauppa:    auki, kiinni
#     kävijä:    palaava, uusi kävijä, nähty (tämä kohtaus nähty), nähty ikkuna (jokin toinen kohtaus nähty), lähettänyt
#     arpa:      arpa 10%   (arvonta, pysyy samana koko vierailun)
#     muu:       puhelin esillä
#   Kun useampi vaihtoehto sopii, voittaa se jolla on eniten ehtoja. Jos niitä on yhtä monta,
#   voittaa tiedostossa ensimmäinen. Mikään ei sopinut: näytetään oletus.
#
#  KIERTOTIE (pieni sivupolku valinnan ja sen kohteen väliin)
#   KIERTOTIE nimi
#   VÄLILLÄ alku -> ikkuna    (lähtö -> kohde, * tarkoittaa mitä tahansa)
#   KUN arpa 15%              (ehto, vapaaehtoinen; kirjoita ennen tekstiä)
#   OTSIKKO: Otsikko
#   teksti... (--- jakaa ruutuihin, 1-2 ruutua)
#   Kiertotie näytetään kerran vierailussa (TOISTUU-rivi toistaa). Se jatkuu aina perille asti.
